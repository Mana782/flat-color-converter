# Flat Color Converter

AIで塗り分けしたPNGを、黒線除去・色の塗り足し・色別/連結領域別レイヤー分割してPSDに変換するブラウザアプリです。

## 公開

`index.html` をリポジトリのルートに置き、GitHub Pagesの Source を **Deploy from a branch**、Branch を **main / (root)** に設定してください。

## 操作

1. AIが塗り分けたPNGをアップロード。
2. 黒判定・主線周囲の削除幅・近似色の統合幅を調整。
3. 「プレビューを更新」を押し、各プレビューとレイヤー数を確認。
4. 色ごと/連結領域ごとを切り替え、PSDを書き出す。

## 注意点

- 黒ベタやインクだまりも主線と同じ扱いで除去します。
- 消去部分は最寄りの有効色を4近傍で伝播して塗り足します。複雑な境界では意図通りにならないことがあります。
- 黒線に接する色境界が太い場合や、生成画像にずれがある場合は手動補正が必要になることがあります。
- 色の正規化はRGB近似による簡易方式です。全色を列挙する処理は画像サイズ・色数によって時間やメモリを消費します。
- 白の除外はRGBの各成分が242以上の色に適用されます。
- PSDはブラウザのメモリ上で作成します。大画像や大量レイヤーではメモリ不足になる場合があります。
- PSDライブラリ `ag-psd` はCDNから読み込みます（初回アクセスに通信が必要）。画像ファイルは送信しません。

## 使用ライブラリ

- [ag-psd](https://github.com/Agamnentzar/ag-psd) (CDN: 6.2.0)
