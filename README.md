# Flat Color Converter

AIが塗り分けたイラストを、CLIP STUDIO PAINTなどで使う下塗りレイヤー付きPSDに変換する、GitHub Pages向けの静的Webアプリです。

## 使い方

1. 塗り分け画像（PNG / JPEG / WebP）を選択します。
2. 黒判定と黒周囲の除去量を調整して「除去範囲」を確認します。
3. 「正規化」「塗り足し結果」を確認します。
4. 必要なら「微小領域の統合」を調整します（初期値0は細部を保護）。
5. 「連結領域ごとにレイヤー分割」を通常はONにして、PSDを書き出します。

## 固定の10色

`#FF4040` `#40FF40` `#4040FF` `#FFE040` `#FF40C0` `#40E0FF` `#FF9A40` `#A040FF` `#B8FF40` `#FF80B0`

AI塗り分けの色むらやJPEG圧縮による微妙な色ずれは、各ピクセルを上記10色のうち最も近い色へ変換することで吸収します。「固定パレット変換の強さ」は正規化プレビューのみの表示設定で、PSDは常に固定10色となります。

## アルゴリズム

- 黒判定：RGB最大値のしきい値以下／透明画素を除去対象にします。黒ベタ・インクだまりも特別扱いしません。
- 追加除去：8近傍で指定ピクセル分、主線マスクを広げます。
- 塗り足し：黒を除いた全ピクセルを固定10色に分類し、4近傍で多点同時に塗り広げます。
- 微小領域：オプションで、指定面積以下の4連結領域を隣接色へ統合します。
- PSD：色単位、または4連結領域単位で透明レイヤーに分けて書き出します。元の線画はPSDに含めません。

## 注意

- 同じ色で直接つながっている別のパーツは、連結領域モードでも分離できません。AI塗り分け時に隣接する別パーツを違う色にするのがおすすめです。
- 画像生成AIはHEX値や線画の形状を必ずしも厳密に維持しません。プレビューで確認してください。
- 主線の除去と塗り足しは近傍ピクセルの色を機械的に延長するものであり、元線画の形状を推定して修復するものではありません。
- 大きな画像やレイヤー数の多い画像は、特にスマートフォンで処理に時間やメモリが必要です。
- PSD出力は外部CDNの `ag-psd` スクリプトを利用します。画像データ自体はブラウザ内で処理します。

## 公開方法

このフォルダの `index.html` と `README.md` をリポジトリの最上位へ置き、GitHub Pagesの `main / (root)` を公開します。
